SYNTHETIC DOCUMENT - created for a course demonstration. Not a company procedure.

## Scope
This instruction covers daily operation of the shadow moire warpage system used for SYN-TM-101 measurements. It is written for lab technicians, not for requesters.

## System startup
Switch on the chamber controller, the camera and the light source. Allow the light source to warm up for 20 minutes before any measurement. Confirm the chamber door interlock is active.

## Grating selection
Select the grating pitch that matches the expected warpage range. Use the fine grating for small connector housings and the coarse grating for large boards. Record the grating in the run log.

## Calibration check
Measure the reference flat at 25 C before the first run of each day. The measured flatness of the reference must be within the value stated on its certificate. If it is not, stop and contact the equipment owner.

## Loading the thermal profile
Load the approved thermal profile file into the chamber controller. Verify the ramp rate, peak temperature and cooling rate on the controller screen against the request before starting the run.

## Data export
Export the height maps for each capture temperature in the native format and as CSV. Name files with the request number, sample ID and capture temperature.

## Shutdown and safety
Allow the chamber to cool below 50 C before opening the door. Wear heat-resistant gloves when removing fixtures. Switch off the light source last.
