SYNTHETIC DOCUMENT - created for a course demonstration. Not a company procedure.

## Required data fields
For each readout, report the sample ID, cycle count, chamber profile reference and the measured values requested.

## Required plots
Plot each measured value against cycle count for all samples.

## Files delivered
Deliver the chamber temperature log as CSV with the summary report as PDF.
