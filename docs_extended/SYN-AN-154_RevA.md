SYNTHETIC DOCUMENT - created for a course demonstration. Not a company procedure.

## Scope
This method measures thermal properties of polymers and resins (SYN-AN-TA): glass transition and melting or crystallisation by DSC, expansion (CTE) by TMA, and decomposition by TGA.

## Required inputs before scheduling
The request must name the property to be measured and where the sample is taken from (which part and area, for example the bulk resin near the gate, or pellets). It should give the temperature range, the heating rate and the atmosphere, or let the lab use its defaults.

## Sample quantity
There is no minimum. One part per lot is usual; send pellets as a reference when comparing moulded parts with the raw material.

## Sample preparation
A small piece is cut from the stated area with a clean blade. Moulded parts may need drying first; the request says if the as-received moisture state matters.

## Test sequence
1. Calibrate the instrument. 2. Weigh and load the sample. 3. Run the heating program in the stated atmosphere. 4. Repeat on the reference, if supplied.

## Reporting
Report the curves, the measured values (Tg, melting point, CTE or decomposition temperature) with the method used to read them, the heating rate, the atmosphere, and where each sample was taken.
