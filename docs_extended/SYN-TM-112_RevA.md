SYNTHETIC DOCUMENT - created for a course demonstration. Not a company procedure.

## Scope
This method exposes samples to rapid temperature changes by transferring them between two liquid baths. It is more severe than air-to-air thermal cycling and is not a substitute for SYN-TM-110.

## Required inputs before scheduling
The request must include the cold and hot bath temperatures, the dwell time in each bath and the number of cycles.

## Transfer
Transfer between baths within 10 seconds. Samples must be fully immersed during each dwell.

## Sample preparation
Samples do not require moisture preconditioning unless the request specifies it.

## Test sequence
1. Perform initial measurements, if requested. 2. Run the specified number of cycles. 3. Dry samples for 1 hour. 4. Perform final measurements.
