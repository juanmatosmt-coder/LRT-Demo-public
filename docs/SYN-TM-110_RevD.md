SYNTHETIC DOCUMENT - created for a course demonstration. Not a company procedure.

## Scope
This method exposes samples to repeated temperature cycles in a chamber. It is an exposure method, not a measurement method. It does not measure warpage at temperature; for warpage during heating, use SYN-TM-101.

## Required inputs before scheduling
The request must include the thermal profile for cycling: minimum and maximum temperature, dwell time at each extreme, ramp rate, and number of cycles. The lab confirms the profile against chamber limits in the equipment database.

## Sample preparation
Precondition samples per SYN-PR-201 before the first cycle.

## Test sequence
1. Precondition samples. 2. Perform initial measurements, if requested. 3. Run the specified number of cycles. 4. Perform intermediate readouts at the requested cycle counts. 5. Perform final measurements.
