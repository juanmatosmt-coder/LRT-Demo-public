SYNTHETIC DOCUMENT - created for a course demonstration. Not a company procedure.

## Required data fields
For each sample at each capture temperature, report: sample ID, temperature, measurement area, coplanarity, and warpage shape (sign convention per the test method).

## Required plots
Provide a plot of coplanarity versus temperature for all samples. Provide contour maps at 25 C before heating, at peak temperature, and at 25 C after cooling.

## Files delivered
Deliver raw data as CSV and a summary report as PDF.

## Requester choices
The request must state whether contour maps are required for every sample or for one representative sample per condition.
